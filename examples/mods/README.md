# Example mods

The modder's guide is [docs/modding/](../../docs/modding/README.md).

All examples use only the public API (`mod.json`, `flags.json`, `text/`, `menus/*.lua`, `scripts/main.lua` with `sh.hooks.on` hooks) and change neither the game's Lua nor its map data. They can be installed together in any combination: each mod listens to events on its own and replaces nobody's files.

- `example_mod/` — a tour of the parts of a mod: changes the "CONTINUE" label of the pause menu (English and Russian text), adds an "EXAMPLE MOD" line with its own menu (an info line and a toggle) to the pause menu, a console command `example_hello`, an `on_map_load` function (the old way) and the `map.load` and `item.picked` hooks (the event bus), and offers an API to other mods through `mod.export`. Its `example_mod/tests/basics_test.lua` shows [Lua tests](../../docs/modding/scripting.md#tests) the modding tools run.
- `cafe_supplies/` — two real items on the café counter (`map0_s01`): an ampoule next to the kitchen knife and a first aid kit at the south end of the counter. They are placed from the `map.load` hook with `sh.world.pickup_create` (Q12 coordinates, taken from the knife; short flag names are the mod's own flags) and picked up through the game's usual question; the flags `cafe_supplies:ampoule_taken` and `cafe_supplies:kit_taken` are declared in `flags.json` and saved by name, so a taken item does not come back after loading a save.
- `ambush_dogs/` — an ambush: when Harry takes the bullets from the bench by the café (`map2_s00`, flags `M2S00_HandgunBullets11` and `12`, the `item.picked` hook), dogs (`Groaner`, `ai = "full"`, facing Harry) appear a few metres behind him on walkable ground (`sh.world.walkable` from Harry's position, with no walls or steps in between): 1 on easy, 2 on normal, 3 on hard (`sh.game.difficulty()`). Once per playthrough — the flag `ambush_dogs:ambush_done`. Offers the API `ambushed()`, `dogs()`, `points_behind(n)` and sends its own event `ambush_dogs:ambushed`. Has its own "AMBUSH: DOGS" page in "Options".
- `screamer_ambush/` — a second mod on the same event of the same map: together with the dogs a flyer (`AirScreamer`) arrives in front of Harry, off to the side (`sh.world.nearest_walkable`). `load_after: ["ambush_dogs"]` puts its handler after the dogs' one (at equal priority the order is the load order), so it already sees the ambush through `sh.mods.get("ambush_dogs").api` and hears `ambush_dogs:ambushed`. Without `ambush_dogs` it works alone. Has its own "AMBUSH: AIR SCREAMER" page in "Options" next to the dogs' page.
- `frontier_arms/` — a new gun `Revolver` (6 rounds, its own attack rows: damage 180, range 9 m; held and aimed like the handgun — the handgun's `rig`) with its own ammunition `RevolverRounds` and its own shot, reload and empty-magazine sounds (`rig.sounds` → names in `sounds/frontier_arms.json`); a machete `Machete`, a new melee weapon with its own attack rows (damage 300/330/200), its own swing sound and `"like": "Axe"` (it strikes like the axe, the axe's `rig`); and a charm `LuckyCharm` with `pickup_once` (it counts as a special item once — the flag `frontier_arms:LuckyCharm_PickedOnce`). The engine gives out the item numbers and the gun's attack rows itself ([data.md](../../docs/modding/data.md)). `scripts/main.lua` logs the `item.given`, `player.quick_heal` and `game.quick_save` hooks. To try it: console `give revolver`, `give revolverrounds`, `give machete`, `equip machete`, `spawn Groaner`, `give luckycharm`.
- `broken_dependency/` — a mod that needs `missing_library`, which is not installed: the game turns it off and writes the reason (`needs mod 'missing_library' >=2.0, which is not installed`) to the log, the console (`mods`) and the "Options > Mods" screen.
- `needs_newer_engine/` — a mod with `"min_engine_version": "99.0.0"`: no such engine exists yet, so the game does not load the mod and writes the reason (`needs engine 99.0.0 or newer, this is 1.0.0`) to the same places, even before it is enabled — on the mods screen it is in the error state at once. `example_mod` shows the usual case: `"min_engine_version": "1.0.0"`.

Mods with `"gameplay": true` (`cafe_supplies`, `ambush_dogs`, `screamer_ambush`, `frontier_arms`) change the game and are marked GAMEPLAY CHANGE on the mods screen.

To install: copy the whole folder into `<game folder>/mods/` (next to the exe), for example `<exe>/mods/ambush_dogs/mod.json`, and start the game. A new mod is off: turn it on (or off, or reorder it) in "Options > Mods" from the title screen or with the console (`mods`, `mods enable example_mod`); a change of the set takes effect after a restart (the game offers one when you leave the page).

To check in the game: console `hooks item.picked` lists the event's handlers in order (`ambush_dogs`, then `screamer_ambush`); `debugmenu options` opens "Options" with the mods' pages; `difficulty easy|normal|hard` before entering the map sets the difficulty for the ambush.
