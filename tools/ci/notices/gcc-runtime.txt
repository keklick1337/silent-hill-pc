Compiler runtime in the Linux binaries
======================================

SilentHillPC, sh-import and libopenal.so.1 are built with GCC. The release build links libgcc and libstdc++ into
them statically, and the package may hold further GCC runtime libraries beside the executable (libatomic.so.1).

- libgcc, libstdc++, libatomic (GCC, Free Software Foundation): GPL-3.0-or-later with the GCC Runtime Library
  Exception 3.1, which permits distributing programs compiled with GCC under terms of their own.
  https://gcc.gnu.org/onlinedocs/libstdc++/manual/license.html
  https://www.gnu.org/licenses/gcc-exception-3.1.html

SDL3 is linked statically into the executable (zlib license, licenses/SDL3.txt); libjpeg-turbo likewise
(licenses/LICENSE-libjpeg-turbo*).
